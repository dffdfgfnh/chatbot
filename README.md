# StudyMate — المساعد الأكاديمي الذكي

تطبيق Streamlit عربي/إنجليزي قابل للتعديل في VS Code لكلية الصناعة والطاقة، جامعة حلوان التكنولوجية الدولية. يحتوي المشروع على نسخة من جدول علوم البيانات الرسمي المرفق للفرق الأربع (الفصل الأول 2026–2027).

## المزايا

- واجهة دردشة عربية/إنجليزية بخط أوضح وأكبر، ومساحة محادثة رئيسية، وأدوات وصول سريع ولوحة جانبية مستوحاة من التصميمين المرفقين. التنفيذ قريب من التصميم وليس نسخة مطابقة بكسلًا ببكسل.
- سجل محادثات جانبي مع إنشاء محادثة جديدة وحذف المحادثة المفتوحة أو أي محادثة بعد التأكيد.
- دخول وتسجيل تجريبي برقم جامعي وكلمة مرور (تخزين كلمات المرور بمشتق PBKDF2، وليس كنص مكشوف).
- جدول فعلي من أوراق Excel الأربع، مع معالجة اختلاف مواضع الأعمدة والخلايا المدمجة والاختيار حسب الفرقة والمجموعة، وبحث وتنزيل CSV.
- محادثات محفوظة محلياً في SQLite بين مرات فتح التطبيق.
- مساعد عام عبر Groq (نموذج `openai/gpt-oss-120b`) للأسئلة المفتوحة في الدراسة والبرمجة والكتابة والتخطيط والموضوعات اليومية، إلى جانب بحث الجدول المحلي. إعداد Groq مطلوب للدردشة التوليدية؛ المشروع لا يدّعي أنه يعادل ChatGPT.
- تسجيل رسالة صوتية من المتصفح أو رفع تسجيل؛ تحويل الصوت إلى نص وإرساله للمساعد يتطلب مفتاح Gemini منفصلاً. زر «استمع للرد» يستخدم أصوات المتصفح على جهاز المستخدم.
- أدوات محلية للمهام والتكليفات، أسئلة استرجاع من النص، بطاقات مراجعة، بحث المدرسين في الجدول، وقوالب تقارير قابلة للتنزيل.
- استخراج من PDF النصي وDOCX وTXT؛ مسار OCR اختياري لملفات PDF المصورة عند تثبيت Tesseract وPoppler وحزم ara/eng.
- خطة مذاكرة قابلة للتنزيل، واجهة متجاوبة، ووضع داكن.

## تشغيل Windows وVS Code

1. ثبّت Python 3.11+ وافتح مجلد المشروع في VS Code.
2. في Terminal:

   ```powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   python -m pip install -r requirements.txt
   streamlit run app.py
   ```

3. افتح الرابط المحلي الظاهر (غالباً `http://localhost:8501`). أنشئ حساباً تجريبياً برقم جامعي تختاره؛ لا يوجد تحقق من نظام الجامعة.

## تفعيل دردشة Groq وتحويل الصوت (اختياري)

أنشئ مفتاحاً من GroqCloud، ثم خزّنه كمتغير بيئة باسم `GROQ_API_KEY` للدردشة العامة. لا ترفع المفتاح إلى GitHub ولا تضعه في الكود. التطبيق يستخدم نموذج `openai/gpt-oss-120b`. تكاليف وحدود الاستخدام مرتبطة بحساب Groq والخطة الحالية. لا يوجد ادعاء بأن هذا يعادل ChatGPT أو يضمن صحة كل إجابة.

على PowerShell لجلسة محلية واحدة:

```powershell
$env:GROQ_API_KEY = "ضع_مفتاح_Groq_محلياً"
streamlit run app.py
```

أو أنشئ `.streamlit/secrets.toml` محلياً (الملف مستثنى من Git) واكتب فيه:

```toml
GROQ_API_KEY = "ضع_مفتاح_Groq_هنا"
```

تحويل التسجيل الصوتي إلى نص ما زال يستخدم Gemini. فعّله اختيارياً بإضافة `GEMINI_API_KEY` من Google AI Studio كمتغير بيئة أو Secret؛ ويعمل التسجيل عادةً على `localhost` أو عند النشر عبر HTTPS بعد السماح للمتصفح باستخدام الميكروفون. تشغيل الرد صوتياً يعتمد على الأصوات العربية/الإنجليزية المتاحة في جهاز المتصفح.

## نشر الويب

ارفع المشروع إلى مستودع GitHub خاص/عام وفق سياسة بياناتكم، ثم اربطه بمضيف يدعم Streamlit. اضبط `GROQ_API_KEY` في صفحة Secrets لدى المضيف للدردشة، و`GEMINI_API_KEY` اختيارياً لتحويل الصوت. احمِ التطبيق قبل استخدامه الفعلي: التسجيل الحالي مفتوح ولا يتحقق من الأرقام، ولا يوجد استرداد كلمة مرور أو إدارة إدارية للحسابات.

SQLite تحفظ البيانات على القرص المحلي. بعض مضيفي الخطط المجانية يعيدون ضبط القرص أو لا يوفرون تخزيناً دائماً؛ استخدم قرصاً دائماً أو قاعدة بيانات مُدارة قبل مشاركة محادثات طلاب حقيقية. لا تستخدم هذا الديمو لتخزين بيانات حساسة.

## OCR

التطبيق يحاول OCR تلقائياً إذا لم يجد نصاً في PDF. ثبّت Tesseract مع حزم اللغات العربية والإنجليزية وPoppler على جهاز/خادم التشغيل. تثبيت حزم Python وحده لا يكفي، وOCR قد يخطئ بحسب جودة الصورة.

## مصادر وحدود البيانات

ملف `data/timetable.xlsx` هو ملف الجدول المرفق بالمحادثة، بأوراق `1st`, `2nd`, `3rd`, `4th`. الخلايا قد تحتوي أكثر من قاعة أو توزيعاً فرعياً كما ورد في المصدر. راجع الجدول المعروض أمام الأصل قبل اعتماده رسمياً. الجدول للترم الأول 2026–2027، ويجب استبداله عند صدور تحديث.
